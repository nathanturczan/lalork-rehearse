THE ESCALATION RULE

Do not invent fixes. If the symptom is not in this document, say:

"I don't have a verified fix for that. Go to the orientation station."

A wrong fix five minutes before a piece is worse than no fix. The orientation station (Leone) handles humans, phones, and anything unusual. This document handles the repetitive laptop questions.

Second rule, from FAILURE_MODES.md: if something breaks, simplify. Don't troubleshoot during the event. A performer who can't connect can listen, share a device, or play acoustically. The piece is not precious.

2. WHAT IT LOOKS LIKE WHEN IT'S WORKING

The Bridge device (in Ableton)

Two tabs at the top: REHEARSAL and PERFORMANCE.

On Saturday everyone uses PERFORMANCE, then presses JOIN LA LAPTOP ORCHESTRA.

Banner states, exactly as they appear:

Banner Color Meaning
● PERFORMING — LA LAPTOP ORCHESTRA purple This is the goal on Saturday.
● REHEARSING — PRIVATE ROOM green Connected, but to a private practice room — not the show.
● CONNECTED green Connected.
connecting... / JOINING LA LAPTOP ORCHESTRA... amber In progress. Wait a few seconds.
✗ CHECK ROOM + WIFI red Not reaching the room. See §4.
disconnected gray Manually disconnected.
ENTER YOUR PRIVATE REHEARSAL CODE gray Idle. Nothing joined yet. Not an error.

The device also displays BPM, Scale (e.g. C Diatonic), and Chord. If those are updating as the conductor moves, it is working.

What "working" sounds like

You play notes; the notes come out inside the current harmony. When the conductor changes chord, held notes re-pitch. Your rhythm, timbre, and when you play are still entirely yours.

3. THE #1 QUESTION: "The Bridge isn't showing the room / it's gray"

A gray ENTER YOUR PRIVATE REHEARSAL CODE device is not broken.

The device always starts idle and never remembers a room. Room codes do not save with a Live Set. Every single time Live opens, every performer must join again.

Fix: click the PERFORMANCE tab → click JOIN LA LAPTOP ORCHESTRA.

This is the most common Saturday question and it has a one-click answer.

Note for whoever is helping: joining is global across the Set. Pressing JOIN on one Bridge joins every Bridge in that Live Set. You do not need to press JOIN on each track. Likewise the REHEARSAL/PERFORMANCE tab is synced across all instances.

4. BRIDGE TROUBLESHOOTING

Red ✗ CHECK ROOM + WIFI

In order: 1. Are they on the venue Wi-Fi? Most common cause. 2. Are they on the PERFORMANCE tab? If they're on REHEARSAL with a typo'd code, they get red. Switch to PERFORMANCE and press JOIN. 3. Press JOIN LA LAPTOP ORCHESTRA again. It retries. 4. Still red → orientation station. Do not keep digging.

Stuck on amber connecting... for more than ~10 seconds

Treat as red, above.

Banner is green/purple but there's no sound

The Bridge is connected — this is an audio problem, not a LALORK problem. 1. Is the track armed / monitor on? 2. Is the track muted, or is the master down? 3. Is Live's audio output the right device (headphones vs interface)? 4. Are they actually playing notes? The device is silent until it receives MIDI — it re-pitches what you play, it does not generate notes on its own.

Sound plays but never follows the harmony

  1. Check the banner is purple/green, not gray.
  2. Check BPM/Scale/Chord fields on the device are changing.
  3. If the fields are frozen, they've lost the room → rejoin (§3).

They typed a room code and it didn't work

The room field accepts the room ID, the slug, or the friendly room name. It is case-insensitive and spaces are OK. But on Saturday nobody should be typing a code at all — that's the REHEARSAL tab. Send them to PERFORMANCE.

They're in ● REHEARSING — PRIVATE ROOM during the show

They're connected to their practice room, not the performance. PERFORMANCE tab → JOIN.

5. ENTER (the web app) — enter.lalaptoporchestra.com

Five paths. Route people by what they brought:

Path For What they do
READ acoustic/traditional players Live notation for their instrument
ABLETON Live users Download Set or Bridge (§1)
MIDI hardware / other DAWs Virtual MIDI out (§6)
JAM anyone, no gear Browser instrument
CODE live coders Strudel (§7)

No install, no sign-in. If a page looks stuck, refresh — that is the standard fix and it is safe.

6. MIDI ROUTING (for the MIDI path)

Straight from the app's own ? help button, so this is current:

Mac: Audio MIDI Setup → Show MIDI Studio → double-click IAC Driver → check "Device is online" → add a port.

Windows: Install and run loopMIDI (tobias-erichsen.de/software/loopmidi.html) → create a port.

Then in Enter's MIDI tab: pick the Port, set Channel (1–16), set Octave (±12 semitones per click), and choose Output:

Output Sends
Scale Pitch Classes Every note of the scale, in one octave. Usually wants transposing up.
Scale Root Root of the scale
Chord Root Root of the chord
Chord Pitch Classes Every note of the chord, in one octave. Usually wants transposing up.
Chord Original Voicing Jazz comping voicing. Some voicings are rootless, so the bass note may not be the chord root — this is expected, not a bug.

If no ports appear in the dropdown: the virtual port wasn't created or Live/their DAW grabbed it exclusively. Redo the IAC/loopMIDI step, then refresh the Enter page. Note: the browser must be allowed MIDI access — if a permission prompt was dismissed, refresh and accept it.

7. STRUDEL (live coders)

Documented flow — not re-verified on Aug 14. Confirm with Tyler/Quargs before relying on it.

  1. enter.lalaptoporchestra.com → Jam → Code
  2. Click Open Strudel (jam pre-loaded)
  3. Press play (Ctrl+Enter)

Working state: a green badge reading ● LIVE — la-laptop-orchestra, with the scale polygon, scale name, and chord name.

Symptom Fix
Red waiting for room "…" badge Room name typo, or the room isn't open yet.
Green badge but no sound Browser blocked audio. Click the page, press play again.
Plays but never changes The room isn't broadcasting — check with the conductor.
Badge invisible in dark mode Known bug. Affects dark themes (seen in Brave). The badge is there, just unreadable. Not a connection problem — don't chase it.

8. KNOWN GOTCHAS (verified Aug 14)

  1. The URLs printed inside the Bridge device are wrong. The device shows rehearse.laptoporchestra.com and enter.laptoporchestra.com — missing the second "la". Those domains do not resolve at all. The real addresses are rehearse.lalaptoporchestra.com and enter.lalaptoporchestra.com. If someone says "the site is down," check what they typed first. (Fixing this needs a device refreeze — do it after Saturday, not before.)

  2. The Bridge never remembers a room. Every Live restart = rejoin. See §3.

  3. Old 207 KB Bridge still in circulation. Anyone who downloaded before Aug 14 may have it. Correct file is 212,811 bytes. Re-download from Enter.

  4. Strudel badge is invisible in dark mode. Cosmetic only.

9. NO VERIFIED FIX — SEND TO ORIENTATION

Be honest about these rather than guessing:

  • Monitoring / performers can't hear themselves. A known past failure. There is no documented self-serve fix. → orientation station.
  • Audio interface / driver problems (incl. MOTU + Windows). → orientation station.
  • Windows-specific Ableton issues. Almost all testing was on Mac.
  • Which sounds/presets to use in the template. Not documented.
  • Incoming-chord accidentals showing wrong sharps/flats. Known open bug. The triads view is correct — use that as the workaround.
  • Conductor cues disappearing. Known open bug, conductor-side. Nothing a performer can do.
  • Anything involving someone's personal Live Set, plugins, or licensing.
